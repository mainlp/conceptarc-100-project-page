# Original ConceptARC examples

These are original ConceptARC corpus tasks, reproduced from the public repository by Victor Vikram Odouard. They are distinct from the generated ConceptARC-100 tasks shown elsewhere on this website.

See `provenance.json` for pinned source URLs and SHA-256 checksums. Regenerate and validate offline with `python3 scripts/prepare_original_examples.py` from the project root; `--check` validates without writing.
